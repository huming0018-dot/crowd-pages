# 众包页面：保留核心与分发边界

本仓含历史 Pages 页面和扩展分发物，不是可复用爬虫。当前暂停众包开发；不要按旧页面安装、采集或恢复更新。这里只整理代码，不改变已部署页面、设备、安装包或更新清单。

## 去留

| 能力 | 结论 |
|---|---|
| `status.html` 状态展示 | 保留项目展示核心：给定状态 RPC 响应，展示计数、任务与最近活动；完整身份/店/状态、固定十分钟锚点的活动折叠有现成离线验证。不是通用监控工具，不证明线上数值真实。 |
| `owner-rate.html` 人工评价 | 保留项目表单适配：店名、评分、理由、比较对象→RPC 请求→成功/失败反馈。完整原页面脚本的合成响应验证通过；评分来源、认证、入库和密钥本地存储不在此完成验收。不提炼公共评分 SDK。 |
| `submit.html`、`sw.js`、`app-manifest.json` | 自动分享提交链不通过完整性鉴别。SW 只接收同源提交页 POST，这部分过滤存在；但提交页先清空全部分享，只处理末条，解析失败也无恢复。人工提交仍有实现，不能因队列缺陷整页宣判无价值；注册、派发、短链与逐条裁决依赖服务端，本次不称完整采集或入库。源码与分发面绑定，本轮不删、不修、不启用。 |
| `index.html`、`apply.html`、`install.html`、`install-mobile.html` | 历史导航/安装说明，无独立工具价值。`apply.html` 固定指向外部 v3.3.1 包；页面“全自动/安全线”等旧文案不是本次承诺。保留为分发兼容材料，不作为新项目安装入口。 |
| Mac/Windows 安装器、ZIP/CRX、`updates.xml` | 历史分发配套，不计通用环境或工具资产。安装器会下载、修改设备并设置定时更新，本次不运行。更新清单声明 v3.5.3 CRX，但固定 Git 树没有该文件；不据此推断当前线上地址必然失败。二进制只登记，不解包或背书其内部实现。 |

## 最小离线复核

仓库根目录，仅需 Node.js：

```sh
node tests/recent_merge.test.cjs
node tests/page_core.test.cjs
```

第一项执行现有状态页活动折叠检查。第二项执行完整评价页脚本的请求/反馈路径，以及原提交页分享队列函数；DOM、RPC、IndexedDB 均为合成替身，不读取真实浏览器或访问网络。输出 `KNOWN FAILURE` 表示成功复现缺陷，不是自动提交功能通过。未验证浏览器排版、真实 API、安装或生产效果。
