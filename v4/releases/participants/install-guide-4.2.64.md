# Mac 参与者安装 · 4.2.64

1. 解压整个安装包，双击 **开始安装.command**。保留整个文件夹，不要单独拖走脚本；无需输入命令。
2. 已有标准参与者安装会自动接续。首次安装会打开图解，按提示在 Chrome 开启“开发者模式”，点“加载已解压的扩展程序”，选择刚准备好的安装目录。
3. 用 Chrome 打开邀请人单独发送的完整邀请链接，点“已安装，继续参与”。首次在客户端同意并开始，按提示登录原小红书账号。

之后自动领取任务、采集和回传。登录失效时，点“登录小红书 / 处理验证”并使用原账号登录，核验通过后自动继续；手动停止、验证码或限流暂停后，处理完成再点“继续采集”。正常任务等待会显示最早下一步，到时自动重新核验，不需要反复点击。随时可停止，待回传记录会保留；诊断可自行选择开启或关闭。

已有安装不要卸载、删除数据或重复报名。若 Chrome 已装旧版“众包美食家”，安装器会暂停，保留旧任务和身份，请联系邀请人安全接续；本包不会自动迁移3.x身份。已有独立私人测试版保留原样；仅没有同ID冲突时另装标准参与者版。旧 KOL 版若不兼容，会暂停并提示使用对应更新方式。若你使用过专用或自定义 Chrome 配置目录，先联系邀请人核对原安装，再按图加载；自动预检只覆盖 Chrome 标准资料目录。Mac14+、Chrome120+；系统与浏览器要求的确认由本人完成。本包未新增 Apple 公证。

更清楚的图解：双击 **安装说明.html**。邀请链接只保存在邀请人的私有入口中，不放在这个公开安装包里。
