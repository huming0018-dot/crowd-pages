# Mac 参与者：从原邀请开始 · 4.2.65

1. **用 Chrome 打开邀请人发来的原参与邀请网页**，保留这个页面。请使用装有采集插件的同一个 Chrome；只下载 ZIP 还没有接续邀请。
2. **已经装好：直接点“已安装，继续参与”**，无需重装。还没安装：从网页下载完整 Mac 包，解压后双击 **开始安装.command**，按图完成 Chrome 加载，再回到原邀请页面点“已安装，继续参与”。
3. 第一次参与时，在插件显示已接续邀请后，同意一次并开始。已经有参与身份或任务，继续原任务，不重新报名。已有小红书有效登录会复用；只有提示登录或验证码时，才需本人在原窗口处理。

任务由系统自动分配、采集和回传。本轮两条小试完成后会等待实验启动，不会继续采下一份任务。诊断可自行开启或关闭；随时可停止，待回传记录保留。

如果63显示“未登录／尚未报名”又提示中台会话恢复：只有这台设备从未成功参与、没有原任务和待回传记录时，才按上面的原邀请路径首次接续。如果以前参与过、有原记录或无法确认，请保留原插件，联系邀请人核对原身份；不要卸载、清数据或重复报名。65会在没有邀请时明确提示先接续，不让未接续的首次参与误走注册。

登录失效时点“登录小红书 / 处理验证”，原账号通过核验后继续；手动停止、验证码或限流暂停，处理完成后再点“继续采集”。正常任务等待显示最早下一步，到时重新核验。中台参与身份与小红书登录是两个状态，按对应提示处理。

已有安装不要卸载或删除数据。若 Chrome 中还有旧版“众包美食家”，安装器会暂停并保留原任务，请联系邀请人安全接续；本包不会自动迁移3.x身份。独立私人测试版保留原样；只有没有同ID冲突时才另装标准参与者版。旧KOL版不兼容时也会暂停。专用或自定义Chrome目录需先核对原安装，自动预检只覆盖标准资料目录。

Mac14+、Chrome120+；系统和浏览器要求的确认由本人完成，本包未新增Apple公证。当前参与者包采集小红书，其他平台由机器节点执行。公开包不含邀请，完整邀请只由邀请人私下发给你，请勿公开转发。
