原安装若提示忙或状态未知，保留现状交给 Owner 核对原状态；不要清空配置、重建身份或反复安装。Intel Mac 尚未实际运行；当前实测宿主为 Apple Silicon Mac。

SHA256SUMS 用于核对下载字节。构建来源及验收边界见 release.json。首次公共工具下载会受网络影响，隔离缓存计时不代表新机总安装耗时。
