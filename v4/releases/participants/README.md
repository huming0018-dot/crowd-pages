已有小红书有效登录会复用。登录失效时点“登录小红书 / 处理验证”，在原窗口使用原账号并等待核验；手动停止、验证码或限流暂停需本人处理后点“继续采集”。中台身份失效按客户端提示处理，不重新报名。开启自动更新且助手接通后，签名升级在可安全切换时保留身份与队列；实际升级以客户端版本、助手ACK和云端诊断为准。
