# 参与者 Mac 安装（4.2.60）

当前安装包为 `crowd-v4.2.60-mac.zip`。解压后双击 `install.command`，按提示在 Chrome 加载扩展；然后打开 Owner 提供的原邀请链接，确认参与后自动领取任务。若参与网页仍提示未发布，可在原插件点击“重新打开邀请”，粘贴完整原邀请链接并“接续邀请”。不要卸载旧插件或新建浏览器资料。

60 将原 54 的结构化采集能力合入正式源码，保留原身份、待回传和人工评价；增加云端节点领取、逐步骤诊断和统一任务关联。诊断由参与者选择开启，关闭不阻断正常领取与回传。SDK 和批量接口由具体云任务显式授权，默认不扩大；当前参与者试验仍为小红书，其他平台由机器工作台执行。

已有标准助手可用 `crowd-v4.2.60-existing-helper-reconnect.zip` 在原目录接续，不替换身份/登录/队列；支持的参与者权限形状与 58 一致。已接专属参与者 OTA 通道的安装，在发布签名通道并开启自动更新后可于空闲时自动升级。KOL 和私人测试通道独立。

`crowd-v4.2.61-recovery-extension.zip` 是独审通过的前进恢复备用件，不在活动通道。60 已 ACK 后如需恢复，Owner 可受控启用更高序号的 61；未 ACK 的自动备份回滚仍保留。恢复包遇到 60 的未决 SDK／批回传状态会停止并保留原队列，等待核对，不重采或拆发；新节点日志仍保存在终端，61 不发送该日志。

以下为 58/59 历史说明，保留供已有安装排查；不把它们作为 60 的前进恢复版本。

下载 `crowd-v4.2.58-mac.zip`，解压后双击 `install.command`。系统若要求确认，请本人确认。按提示在 Chrome 扩展页加载刚打开目录，再打开 Owner 邀请链接，勾选同意并开始。任务自动领取，成功回传由后台回执确认。可选运行诊断向 Owner 报错，关闭后清除云端状态与历史。

首次安装只需一次；后续已签名更新保留身份和待回传证据，遇登录/验证码由本人处理。此安装需要 macOS 14+、Chrome 120+。现有旧安装不会被覆盖；不要卸载旧身份或另建浏览器资料。当前试验包覆盖小红书参与者采集，七平台机器工作台属于另一入口。

`crowd-v4.2.59-recovery-extension.zip` 为 Owner 的受控恢复包，普通参与者不要直接安装。文件未含账号凭据或 Owner 密钥。核验：`shasum -a 256 -c SHA256SUMS.txt`。新参与者通道为 `../channel-participants.json`；恢复 envelope 不在活动通道。

Mac 人工下载包位于本目录；OTA 为兼容已审 helper 固定 URL 校验，使用上级目录同字节 `crowd-v4.2.58-participant-extension.zip`。恢复同字节别名为上级 `crowd-v4.2.59-participant-recovery-extension.zip`。签名 envelope 指向提交 SHA 固定的不可变 URL。

当前58包含56的自动任务满额换任务、日配额等待、两条验收后等待实验启动并自动继续修复。59是当前独立恢复包，不在活动通道。已接专属参与者通道的54/56在自动更新开启且原插件空闲时通过OTA收到58，无需重新安装。已有标准helper安装会自动读取原helper配置并在原目录重新接通，不改Profile、身份、登录与待回传记录；旧KOL权限安装明确拒绝硬迁移。

已有标准更新助手也可单独下载 `crowd-v4.2.58-existing-helper-reconnect.zip`，解压双击 reconnect.command。原helper/config/state和注册文件先备份，保留全部原偏好，busy/pending时拒绝；不强制重载，等原插件正常空闲OTA。58修复任务换取期间的监控误报警，59保留全部56/58状态修复，只回滚回传节奏。新Mac完整包已同时支持首次安装和原标准安装接续。
