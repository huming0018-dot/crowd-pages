# Mac Pro 参与者安装（4.2.96 灰度通道）

安装包：`crowd-v4.2.96-pro-mac-r3.zip`。R3统一安装与接续的浏览器资料检查，修复日常Chrome旧3.5.3与原采集资料共存时的误拦截。此前V4/R2完整实机入口均被安全拒绝，未覆盖原插件；请用R3接续，不要卸载原插件或重新报名。日常旧扩展保持原样。

本包接续原参与身份、进度、评分与回执，不要卸载旧插件或重新报名。支持 macOS 14+ 的 Apple/Intel Mac。

1. 完整解压安装包，不要单独移动其中的文件。
2. 双击「开始安装.command」，按自动检查提示完成安装或接续。
3. 打开原插件；确认显示 Pro 已就绪，再点「继续采集」。任务由中心分配，收到本批全部回执后自动停止。可随时点「停止」。

Pro 使用本机已有的合法 SDK、Python 环境及本人原账号绑定；安装包只含自有适配器和更新助手。没有这些依赖时，会明确显示未就绪，请联系邀请人配置本机环境，不要反复登录、扫码或重装。平台自己要求验证码时须由本人完成。

新宿主读取独立 Pro OTA 通道；旧设备留在原通道。采集中或有未知回传时延后更新，确认停车后恢复检查。适配器/宿主依赖变更使用本接通包在空闲状态升级，保留原账号与记录。

当前普通参与者接口先接小红书正文任务；要求评论的任务明确拒绝，不偷偷关闭。Pro 的评论、媒体和导出在原运行工作区保留；不能把安装成功当作真实采集已完成。
