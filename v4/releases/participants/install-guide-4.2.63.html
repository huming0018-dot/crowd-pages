常见情况

以前装过，怎么办？

已有标准参与者安装会接续原目录和身份。若 Chrome 已装旧版“众包美食家”，会暂停并保留旧任务，请联系邀请人安全接续；本包不会自动迁移3.x身份。独立私人测试版保持原样；仅没有同ID冲突时可另外安装标准参与者版，私人版身份和待回传记录不会迁移过来。旧 KOL 版若不兼容，会暂停并提示使用对应更新方式。不要卸载原扩展或清数据。若使用过专用或自定义 Chrome 配置目录，先联系邀请人核对原安装；自动预检只覆盖 Chrome 标准资料目录。

Mac 提示无法打开，或需要本人确认

先核对安装包来自邀请人给你的地址。若只是打开确认，按系统提示处理；若提示“无法验证开发者”，可在“系统设置 → 隐私与安全性”查看是否提供“仍要打开”，由本人决定。若提示包含恶意软件或没有该选项，停止并联系邀请人。不要运行关闭系统保护或移除安全标记的命令。

没有 Google Chrome

先从 Google 官方页面下载 Chrome，安装后重新双击“开始安装.command”。如已安装，打开 Chrome 菜单中的“关于 Google Chrome”完成更新。本包面向 macOS14+、Chrome120+；不会替你修改 Chrome 安全设置。

之后还要做什么？

任务会自动领取、采集和回传。登录失效时，点“登录小红书 / 处理验证”打开原工作窗口；原账号登录通过核验后自动继续。手动停止、验证码或限流暂停后，处理完成再点“继续采集”。运行诊断可自行选择开启或关闭。随时可停止，已经形成的待回传记录会保留。

为什么包里没有邀请链接？

安装包可以公开校验；邀请链接只由邀请人私下发给你。请不要把完整邀请转发到公开群或代码仓库。

本页可以离线打开，无统计脚本、不读取账号或 Cookie。当前参与者安装包采集小红书；其他平台由系统的机器节点执行。安装器没有新增 Apple 公证；系统与 Chrome 必须的确认由本人完成。
